# reference-project

A Manifold Studio project

This project was created with [Manifold Studio](https://github.com/tonyhschu/manifold-cad-live-preview), a modern TypeScript framework for 3D CAD model development.

## Getting Started

### Development Mode

Start the development environment:

```bash
npm run dev
```

This starts the Manifold Studio CLI which automatically:

- **Discovers Models**: Finds your models (`main.ts` + `components/*.ts`)
- **Compiles Pipeline**: Generates pipeline entries automatically
- **Starts Server**: Single server (port 3000) with integrated pipeline compiler
- **Watches Files**: Updates automatically when you change model files
- **Live Preview**: Opens your browser with real-time 3D rendering
- **Parameter Controls**: Adjust model parameters using the control panel
- **Export Options**: Download your models as OBJ or GLB files
- **Hot Reloading**: See changes instantly without page refreshes

### Legacy Development Mode

For compatibility with the old dual-server approach:

```bash
npm run dev:legacy
```

This runs the legacy dual-server setup if needed for debugging.

### Adding Models

Simply add TypeScript files to your project - the CLI discovers them automatically:

1. **Main model**: Edit `main.ts` for your primary model
2. **Component models**: Add `.ts` files in `components/` (e.g., `components/my-part.ts`)
3. **Automatic discovery**: New models appear in the configurator immediately
4. **No manual setup**: No need to edit pipeline files or configuration

Example model structure:

```typescript
// components/my-part.ts
declare const manifold: any;

function createMyPart(params: { width: number; height: number }) {
  return manifold.cube([params.width, params.height, params.width]);
}

export default {
  name: "My Part",
  description: "A customizable part",
  parameters: {
    width: { value: 10, min: 1, max: 50, step: 1 },
    height: { value: 10, min: 1, max: 50, step: 1 },
  },
  generateModel: createMyPart,
};
```

The CLI automatically detects this file and adds it to your configurator!

### Project Structure

```
reference-project/
├── src/
│   └── main.ts          # UI entry point (simplified)
├── main.ts              # Your main 3D model
├── components/          # Model components (auto-discovered by CLI)
│   ├── example.ts       # Example sphere component
│   └── wheel.ts         # Example wheel component
├── temp/                # Generated by CLI (gitignored)
│   ├── pipeline.js      # Compiled pipeline with all models
│   └── manifest.json    # Model metadata and parameters
├── package.json         # Project dependencies
├── vite.config.ts       # UI server configuration
├── tsconfig.json        # TypeScript configuration
└── index.html           # HTML bootstrap
```

## Adding Dependencies

You can install any NPM package to enhance your models:

```bash
# Example: Add D3 for data visualization
npm install d3

# Example: Add math utilities
npm install mathjs
```

Then import and use them in your model:

```javascript
import * as d3 from "d3";
import { evaluate } from "mathjs";
```
